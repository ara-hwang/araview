# 사용법

사용자용 안내입니다. 전체 기능/기술 명세는 `../SPEC.md`가 진실입니다.

## 단축키

기본값 진실은 `app/src/settings.rs`의 기본 단축키 표이며, 설정에서 재할당할 수 있습니다. `+` 키는 단독으로 `+`, 수식키와 함께는 `Ctrl++`처럼 표기합니다. 규격 표는 `SPEC.md` §14를 따릅니다. `T`(항상 위)와 `Ctrl+Shift+E`(탐색기에서 보기) 등 Windows 셸 연동 단축키도 있습니다.

- **파일/탐색**: `Ctrl+O`(열기), `ArrowLeft`/`ArrowRight`(이전/다음)
- **이동**: `Ctrl+ArrowLeft`/`Ctrl+ArrowRight`/`ArrowUp`/`ArrowDown`(팬; 웹툰 모드에서는 이전/다음·스크롤 이동으로 바뀌고 다이얼로그/입력 포커스·그리드 표시 중에는 동작하지 않음)
- **점프**: `PageUp`/`PageDown`(10장), `Home`/`End`(처음/마지막)
- **줌**: `=`, `-`, `0`(초기화), `1`(가로 맞춤), `2`(세로 맞춤), `3`(화면 맞춤)
- 확대/축소는 부드럽게 이동하며, Windows에서 애니메이션 효과를 끄면 즉시 적용됩니다.
- **이미지 조작**: `R`(시계 회전), `Shift+R`(반시계 회전), `H`(좌우 반전), `V`(상하 반전). 맞춤(`1`/`2`/`3`)과 이미지 조작은 양쪽 보기에서 동작하지 않습니다(헤더 버튼과 우클릭 메뉴 항목도 비활성).
- **보기**: `I`(EXIF), `G`(썸네일 그리드), `F11`(전체화면), `T`(항상 위), `B`(배경 순환)
- **애니메이션 이미지 (GIF/APNG/WebP/AVIF/JXL)**: `Space`(재생/정지), `,`/`.`(이전/다음 프레임). 단일 보기에서만 재생하고, 그 밖(정지 이미지·웹툰/양쪽 보기)은 첫 프레임 정지(`SPEC.md` §7.5). 하단 컨트롤은 가로를 모두 채우고, 프레임 카운터는 4자리 고정 슬롯을 쓰며 10,000프레임 이상은 앞자리를 줄임표로 대체한다.
- **복사/외부**: `Ctrl+C`(이미지 복사), `Ctrl+Shift+C`(경로 복사), `Ctrl+Shift+T`(글자 인식 후 복사, Windows 전용), `Ctrl+Shift+H` 또는 헤더 글자 강조 버튼(글자 강조 켜기/끄기, 켜면 드래그로 한 글자씩, 더블클릭으로 단어 선택 후 `Ctrl+C`, Windows 전용), `Ctrl+Shift+E`(탐색기에서 보기), `Ctrl+Shift+O`(기본 앱으로 열기)
- **파일 관리**: `Delete`(휴지통 이동), `F2`(이름 변경)
- **기타**: `Ctrl+K`(명령 팔레트), `Escape`(이미지 닫기)
- **그리드 내부**: 화살표(이동), `Home`/`End`, `PageUp`/`PageDown`, `Enter`(열기), `Esc` 또는 `G`(닫기)

휠/마우스 기본값은 `SPEC.md` §14.2를 따릅니다. 휠 위/아래는 이전/다음, `Ctrl+휠`은 확대/축소, 왼쪽 드래그는 팬, 더블클릭은 전체화면, 우클릭은 컨텍스트 메뉴입니다.

## 설정 항목

설정은 헤더의 설정 버튼으로 여는 다이얼로그에서 관리합니다. 위쪽 탭으로 분류를 전환합니다. 아래는 자주 쓰는 항목만 요약한 것이며, 전체 목록과 기본값은 `SPEC.md` §13이 진실입니다.

- **일반 / Language**: 한국어 / English (OS 언어 자동 감지, 변경 즉시 적용)
- **일반 / 테마**: 앱 전체 밝기를 `시스템 설정 따르기`(기본), `라이트`, `다크` 중에서 고릅니다. `시스템 설정 따르기`는 Windows 테마가 라이트·다크로 바뀌는 즉시 따라가므로, 설정 앱에서 테마를 바꾸면 앱을 다시 열지 않아도 화면이 바로 바뀝니다.
- **일반 / Navigation**: 끝에서 정지 또는 루프 이동
- **성능 / 이미지 미리 로드**
  - `off`: 현재 이미지만 유지
  - `nearby`: 인접 이미지 중심 프리패치
  - `extended`: 더 넓은 범위 프리패치
  - `folder`: 같은 폴더(현재 목록)의 모든 이미지를 가까운 순으로 미리 로드
- **성능 / 캐시 최대 크기**: 페이지 캐시가 보관할 디코드 결과의 바이트 상한을 `512 MB`, `1 GB`(기본), `2 GB` 중에서 고릅니다. 미리 로드 범위와 따로 적용됩니다.
- **성능 / 캐시 보관**: `persistent`는 앱을 다시 열어도 썸네일과 변환 이미지를 재사용하고, `temporary`는 현재 실행 중에만 유지합니다. 기본값은 `persistent`이며 변경은 다음 실행부터 적용됩니다.
- **성능 / 클라우드 파일 자동 내려받기**: 클라우드에만 있는 파일(OneDrive 온디맨드 자리표시자 등)을 썸네일이나 옆 페이지 미리 로드로 미리 내려받을지 정합니다. 끄면(기본) 실제로 화면에 들어온 파일만 내려받고, 목록에는 구름 아이콘으로 클라우드 전용 것을 표시합니다. 켜면 로컬 파일과 같은 규칙으로 미리 내려받습니다.
- **성능 / 캐시 관리**: 현재 임시 또는 영구 캐시의 전체 사용량과 종류별 사용량을 확인하고, 종류별 또는 전체 캐시를 삭제할 수 있습니다. 현재 화면에서 사용 중인 파일은 삭제하지 않습니다.
- **성능 / 표시 해상도**: 아주 큰 이미지를 긴 변 기준으로 축소해 표시합니다(`원본`, `4K`=3840px, `Full HD`=1920px). 원본 파일은 바뀌지 않고, 복사·탐색기 열기·기본 앱 열기는 원본 기준입니다.
- **보기 / 이미지 표시**: 메인 이미지의 `자동`, `부드럽게`, `픽셀 보존` 중 표시 스케일링을 고릅니다. 자동 모드는 2배 이상 확대하면 픽셀을 보존하고, 그 아래에서는 부드럽게 표시합니다. 뷰어를 우클릭해 `이미지 표시` 하위 메뉴에서도 바로 바꿀 수 있습니다. 픽셀 보존은 확대 배율에서만 적용되며, 축소 표시(화면 맞춤 등)에서는 설정과 무관하게 항상 부드럽게 보간해 스크린톤 깨짐을 막습니다.
- **확장자 연결(Windows 전용)**: 연결을 바꾸면 해당 확장자의 Windows 기본 앱 선택 창이 열립니다.
- **확장자 / 탐색기 썸네일**: PSD, 코믹 아카이브(CBZ/ZIP), HEIC/HEIF, EXR, 지원 RAW 형식의 파일 아이콘 축소판을 켜고 끕니다. 기존 PSD 등록은 `지원 형식 모두 적용`으로 확장할 수 있습니다. 코믹은 지정 표지를 우선하고 지정이 없으면 자연 정렬의 첫 이미지를 표시합니다. 기본 앱 연결은 바뀌지 않으며, 끄면 이전 사용자별 썸네일 핸들러가 복원됩니다. 탐색기의 미리보기 창(`Alt+P`)은 지원하지 않습니다. 적용 후 탐색기를 다시 시작하거나 썸네일 캐시를 지워야 반영될 수 있습니다.
- **보기(View Mode)**: `single`, `left-to-right`, `right-to-left`, `webtoon` (양쪽 모드는 2장씩 넘김)
- **보기 / 상단 메뉴바 숨기기**: 이미지를 보는 동안 상단바와 앱의 최소화·최대화·닫기 버튼을 함께 숨깁니다. 창 위쪽 24 논리 px 영역 어디에나 포인터를 올리면 메뉴바와 창 버튼이 잠시 나타나며, 위쪽 48 논리 px를 벗어나거나 다른 창으로 전환하면 닫힙니다. 나타난 메뉴바의 숨기기 해제 버튼이나 보기 설정에서 해제할 수 있습니다. UI 자동 숨김에도 같은 상단 동작을 적용하며, 홈에서는 설정을 유지한 채 상단바를 항상 표시합니다.
- **보기 / UI 자동 숨김**: 가장자리에서 다시 나타나는 상단바, 이미지 목록 도크, 상태바는 이미지 위에 겹쳐 표시됩니다. 창 아래쪽 24 논리 px 안에 포인터를 올리면 도크와 상태바가 나타나며, 나타난 뒤에는 아래쪽 150 논리 px 안에서 유지됩니다. UI가 나타나거나 사라져도 이미지 크기와 위치, 웹툰 읽기 위치는 유지됩니다. 도크를 어느 가장자리에 배치해도 동일하며, 자동 숨김을 끄면 원래처럼 UI 공간을 따로 확보합니다.
- **보기 / 휠 동작**: 수식키 없이 휠을 굴릴 때 `이전/다음 이미지`로 넘길지, `확대/축소`할지 고릅니다. `Ctrl+휠`처럼 수식키를 붙인 조합별 동작은 단축키 탭의 휠 맵에서 바꿉니다.
- **웹툰 모드 세부 설정**: 웹툰 이미지는 간격 없이 이어지고, 페이지 경계선, Fit width, 현재 위치 표시, 썸네일 점프를 설정합니다. 현재 위치 표시는 현재 장과 전체 읽기 진행률을 보여주며, 썸네일 점프를 켜면 읽기 영역의 버튼으로 그리드를 열 수 있습니다.
- **읽기**: 만화 파일(아카이브)을 다시 열 때 마지막으로 본 페이지에서 이어보기 (끄면 항상 첫 페이지, 같은 경로의 파일이 다른 내용으로 바뀌었으면 기존 위치를 무시하고 첫 페이지에서 열기), 만화 아카이브를 열면 자동으로 양쪽 보기 (ComicInfo의 `Manga`가 `YesAndRightToLeft`면 우→좌, `No`면 좌→우, 그 외는 좌→우, 보기 모드를 직접 고르면 아카이브 보는 동안만 적용되고 설정값은 그대로여서 일반 이미지는 아카이브 전 설정대로 열림), 양쪽 보기에서 표지 단독 표시 (첫 페이지를 혼자 보여주고 그 뒤를 `2-3`, `4-5` 순서로 짝을 맞춤, 표지를 따로 지정하거나 해제한 만화는 그 지정이 우선), 양쪽 보기에서 넓은 페이지 단독 표시 (펼침면을 한 장으로 스캔한 가로 페이지를 반쪽 크기로 줄이지 않고 한 화면에 크게 보여줌)
- **손상 파일 건너뛰기**: 켜면 열 수 없는 파일을 건너뛰고 다음 이미지로 넘어갑니다(양쪽 보기는 화면 단위). 끄면 그 자리에 다시 시도와 홈 버튼이 있는 오류 화면을 보여주며, 이전/다음으로 계속 넘길 수 있습니다. 파일을 여는 데 실패하면 상단바 아래 콘텐츠 영역의 가로·세로 중앙에 오류 안내와 버튼을 표시하며, 다시 시도는 같은 파일을 다시 엽니다.
- **시작**: 홈 화면 표시 또는 마지막 파일 자동 열기

홈 화면의 최근 파일 목록은 가로 카드 줄입니다. 카드가 목록 폭을 넘으면 가로로 스크롤해서 넘겨 보고, 세로 휠(일반 마우스)도 가로 이동으로 동작합니다. 최근 파일 카드와 가로 이미지 도크(상/하)는 항목 아래에 스크롤바용 여백을 두어 서로 겹치지 않습니다. 카드를 클릭하면 그 파일을 열고, 카드의 X 버튼으로 목록에서 하나씩 뺄 수 있습니다. 긴 파일명은 한 줄에서 줄임표로 자르고, 카드에 마우스를 올리면 전체 경로를 보여줍니다.

최근 파일 목록에서 아카이브 항목은 읽기 진도(예: `12/340 페이지`)를 함께 보여줍니다. 진도 기록에는 파일이 바뀌었는지 확인할 identity(크기와 수정 시각)가 함께 저장되므로, 같은 경로의 파일이 다른 내용으로 교체됐으면 옛 진도는 보여주지 않고 파일을 열면 첫 페이지에서 시작합니다.

CBZ/ZIP 파일에 `ComicInfo.xml`이 들어 있으면 정보 패널(`I`) 맨 위의 만화 정보 섹션에서 시리즈, 권 번호, 작가, 줄거리 같은 메타데이터를 읽을 수 있습니다. 이 섹션이 필요 없으면 설정 보기 탭 읽기 섹션의 `정보 패널에 만화 정보(ComicInfo.xml) 표시`를 끄세요(양쪽 보기의 표지 판정은 그대로 동작합니다).

만화마다 표지를 따로 정할 수 있습니다. 만화를 연 상태에서 페이지를 우클릭하고 `이 페이지를 표지로 지정` 또는 `표지 지정 해제`를 고르세요(명령 팔레트의 `현재 페이지 표지 지정/해제`도 같습니다). 표지로 지정한 페이지는 설정과 상관없이 양쪽 보기에서 혼자 보이고, 표지를 해제한 만화는 첫 페이지부터 두 장씩 보입니다. 이어진 페이지를 차례로 지정하면 여러 장을 표지로 둘 수 있습니다. 이 지정은 만화 파일 안의 `ComicInfo.xml`에 저장되므로 CBZ/ZIP 파일이 수정되고(수정 시각 갱신, 백업 없음), 파일을 옮기거나 다른 뷰어로 열어도 유지됩니다. 표지를 지정해 파일이 수정돼도 읽던 위치 기록은 그대로 이어집니다.

큰 이미지(2MP 이상)는 지원되는 JPEG와 일반 RGB PNG에서 저해상 프리뷰를 먼저 표시하고, 원본이 준비되면 페이드 없이 선명하게 교체합니다. ICC 프로파일, 투명도, 인터레이스, 애니메이션 등 프리뷰가 안전하지 않은 입력은 기존 디코드 경로를 씁니다. 프리뷰 상태에서는 복사와 이미지 분석 기능을 full 이미지가 준비될 때까지 사용할 수 없습니다.

고대비 모드는 별도 토글 없이 Windows 대비 테마를 따릅니다. 애니메이션은 Windows "애니메이션 효과" 설정이 꺼져 있으면 줄입니다.

설정과 최근 파일 목록은 `settings.json`에 저장됩니다(Windows `%APPDATA%\com.araview.viewer\`). 개발 빌드는 식별자 `com.araview.viewer.dev`로 별도 저장되며, 캐시 위치는 `development.md`의 표를 따릅니다. 1.x에서 올라오면 같은 파일을 이어받습니다. 전체 설정 표와 기본값은 `SPEC.md` §13을 따릅니다.

## 진단 정보와 로그

문제를 제보할 때 설정 일반 탭의 `진단 정보 복사`를 누르면 환경 요약이 클립보드에 들어갑니다. 담기는 항목은 버전과 빌드 종류, 운영체제와 빌드, 아키텍처, 언어·테마·보기 모드·캐시 모드·표시 해상도, 이미지 코덱 라이브러리 존재 여부, 캐시와 로그 경로, 최근 경고·오류 8건입니다. 사진 경로와 파일 이름, 환경 변수 값은 담지 않고, 사용자 폴더 경로는 `<home>`으로 가립니다. 이 정보는 어디로도 전송되지 않습니다(클립보드까지만).

앱은 경고와 오류를 로그 파일에도 남깁니다. 위치는 Windows `%LOCALAPPDATA%\com.araview.viewer\logs\araview.log`이고, 개발 빌드는 `com.araview.viewer.dev` 폴더를 씁니다. 한 파일이 1 MiB를 넘으면 이전 기록을 `araview.log.1`로 옮기고 새로 쓰며, 이전 파일은 하나만 유지합니다. 앱을 다시 열어도 남습니다. 기본 기록 범위는 경고와 오류이고, 환경 변수 `RUST_LOG`로 넓힐 수 있습니다. 로그 줄에는 앱이 남기는 오류 문구에 섞인 파일 경로가 들어갈 수 있으므로, 남에게 보내기 전에 확인하세요.

## 업데이트 확인

시작할 때 새 버전을 1회 자동으로 확인합니다(기본 켜짐, 설정 일반 탭의 `시작 시 자동 확인`에서 끌 수 있음). 자동 확인은 새 버전이 있을 때만 대화상자를 띄우고, 최신이거나 실패하면 알리지 않습니다. 업데이트 채널은 하나이며 항상 최신 정식 릴리스를 확인합니다(설치된 버전보다 낮은 버전으로 내려가지는 않습니다). 설정 일반 탭의 `새 버전 확인` 버튼이나 명령 팔레트(`Ctrl+K`)의 `업데이트 확인`으로는 언제든 직접 확인할 수 있습니다. 새 버전이 있으면 대화상자에서 다운로드를 시작할 수 있습니다. 다운로드 중에는 진행 막대와 받은 크기가 보이고 `취소`로 그만둘 수 있습니다. 다운로드가 끝나면 앱이 설치 관리자에게 인계하며 잠시 닫히고, 설치가 끝난 뒤 새 버전이 자동으로 실행됩니다.

릴리스와 서명 절차는 maintainer용 `releasing.md`를 봅니다.
