# 사용법

사용자용 안내입니다. 전체 기능/기술 명세는 `../SPEC.md`가 진실입니다.

## 단축키

기본값 진실은 `src/constants/shortcuts.ts`(`DEFAULT_SHORTCUTS`)이며, 설정에서 재할당할 수 있습니다. 규격 표는 `SPEC.md` §14를 따릅니다.

- **파일/탐색**: `Ctrl+O`(열기), `ArrowLeft`/`ArrowRight`(이전/다음)
- **이동**: `ArrowLeft`/`ArrowRight`/`ArrowUp`/`ArrowDown`(팬; 웹툰 모드에서는 이전/다음·스크롤 이동으로 바뀌고 다이얼로그/입력 포커스·그리드 표시 중에는 동작하지 않음)
- **점프**: `PageUp`/`PageDown`(10장), `Home`/`End`(처음/마지막)
- **줌**: `=`, `-`, `0`(초기화), `1`(가로 맞춤), `2`(세로 맞춤), `3`(화면 맞춤)
- **이미지 조작**: `R`(시계 회전), `Shift+R`(반시계 회전), `H`(좌우 반전), `V`(상하 반전), `Ctrl+S`(편집 저장)
- **보기**: `I`(EXIF), `G`(썸네일 그리드), `F11`(전체화면), `T`(항상 위), `B`(배경 순환)
- **GIF**: `P`(재생/정지), `,`/`.`(이전/다음 프레임). 단일 보기에서만 동작하며 정지 GIF·웹툰/양쪽 보기에서는 원래 애니메이션으로 재생됩니다.
- **복사/외부**: `Ctrl+C`(이미지 복사), `Ctrl+Shift+C`(경로 복사), `Ctrl+Shift+E`(탐색기에서 보기), `Ctrl+Shift+O`(기본 앱으로 열기)
- **파일 관리**: `Delete`(휴지통 이동), `F2`(이름 변경)
- **기타**: `Ctrl+K`(명령 팔레트), `Escape`(이미지 닫기)
- **그리드 내부**: 화살표(이동), `Home`/`End`, `PageUp`/`PageDown`, `Enter`(열기), `Esc` 또는 `G`(닫기)

휠/마우스 기본값은 `SPEC.md` §14.2를 따릅니다. 휠 위/아래는 이전/다음, `Ctrl+휠`은 확대/축소, 왼쪽 드래그는 팬, 더블클릭은 전체화면, 우클릭은 컨텍스트 메뉴입니다.

## 설정 항목

설정은 헤더의 설정 버튼으로 여는 다이얼로그에서 관리합니다. 왼쪽 사이드바로 분류를 전환합니다.

- **일반 / Language**: 한국어 / English (OS 언어 자동 감지, 변경 즉시 적용)
- **일반 / Navigation**: 끝에서 정지 또는 루프 이동
- **성능 / 이미지 미리 로드**
  - `off`: 현재 이미지만 유지
  - `nearby`: 인접 이미지 중심 프리패치
  - `extended`: 더 넓은 범위 프리패치
  - `memory-1gb` / `memory-2gb`: 프론트 이미지 메타데이터 캐시 항목 한도
- **성능 / 캐시 보관**: `persistent`는 앱을 다시 열어도 썸네일과 변환 이미지를 재사용하고, `temporary`는 현재 실행 중에만 유지합니다. 기본값은 `persistent`이며 변경은 다음 실행부터 적용됩니다.
- **성능 / 캐시 관리**: 현재 임시 또는 영구 캐시의 전체 사용량과 종류별 사용량을 확인하고, 종류별 또는 전체 캐시를 삭제할 수 있습니다. 현재 화면에서 사용 중인 파일은 삭제하지 않습니다.
- **성능 / 표시 해상도**: 아주 큰 이미지를 긴 변 기준으로 축소해 표시합니다(`원본`, `4K`=3840px, `Full HD`=1920px). 원본 파일은 바뀌지 않고, 저장·복사·탐색기 열기·기본 앱 열기는 원본 기준입니다.
- **보기 / 이미지 표시**: 메인 이미지의 `자동`, `부드럽게`, `픽셀 보존` 중 표시 스케일링을 고릅니다. 자동 모드에서는 픽셀 아트 자동 감지를 켜고, 판별이 불확실하면 부드러운 표시를 사용합니다. 픽셀 보존은 확대 배율에서만 적용되며, 축소 표시(화면 맞춤 등)에서는 설정과 무관하게 항상 부드럽게 보간해 스크린톤 깨짐을 막습니다.
- **확장자 연결**: 연결을 바꾸면 해당 확장자의 Windows 기본 앱 선택 창이 열립니다.
- **보기(View Mode)**: `single`, `left-to-right`, `right-to-left`, `webtoon` (양쪽 모드는 2장씩 넘김)
- **웹툰 모드 세부 설정**: 이미지 간격, 페이지 경계선, Fit width, 현재 위치 표시, 썸네인 점프를 설정합니다. 현재 위치 표시는 현재 장과 전체 읽기 진행률을 보여주며, 썸네인 점프를 켜면 읽기 영역의 버튼으로 그리드를 열 수 있습니다.
- **읽기**: 만화 파일(아카이브)을 다시 열 때 마지막으로 본 페이지에서 이어보기 (끄면 항상 첫 페이지), 양쪽 보기에서 표지 단독 표시 (ComicInfo의 `FrontCover`, 없으면 첫 페이지를 혼자 보여주고 그 뒤를 `2-3`, `4-5` 순서로 짝을 맞춤)
- **시작**: 홈 화면 표시 또는 마지막 파일 자동 열기

최근 파일 목록에서 아카이브 항목은 읽기 진도(예: `12/340 페이지`)를 함께 보여줍니다.

CBZ/ZIP 파일에 `ComicInfo.xml`이 들어 있으면 정보 패널(`I`) 맨 위의 만화 정보 섹션에서 시리즈, 권 번호, 작가, 줄거리 같은 메타데이터를 읽을 수 있습니다. 읽기 전용이라 파일을 수정하지 않습니다. 이 섹션이 필요 없으면 설정 보기 탭 읽기 섹션의 `정보 패널에 만화 정보(ComicInfo.xml) 표시`를 끄세요(양쪽 보기의 표지 판정은 그대로 동작합니다).

큰 이미지(약 2MP 또는 1.5MB 이상)는 캐시된 저해상 프리뷰가 먼저 깔리고 원본이 준비되면 선명하게 바뀝니다. 프리뷰는 썸네일 캐시를 재사용하므로 같은 이미지를 두 번째 열 때부터 즉시 표시됩니다.

고대비 모드는 별도 토글 없이 Windows 대비 테마(`forced-colors`)와 시스템 고대비 설정(`prefers-contrast`)을 따릅니다.

설정과 최근 파일 목록은 Tauri Store(`settings.json`)에 저장됩니다. 전체 설정 표와 기본값은 `SPEC.md` §13을 따릅니다.

## 업데이트 확인

앱은 시작 시 업데이트를 확인하지 않습니다. 설정 일반 탭의 `지금 확인` 버튼이나 명령 팔레트(`Ctrl+K`)의 `업데이트 확인`으로 직접 확인할 때만 네트워크를 씁니다. 새 버전이 있으면 대화상자에서 다운로드를 시작할 수 있습니다. 다운로드가 끝나면 앱이 설치 관리자에게 인계하며 잠시 닫히고, 설치가 끝난 뒤 새 버전이 자동으로 실행됩니다.

릴리스와 서명 절차는 maintainer용 `releasing.md`를 봅니다.
